# Amazon Sales & Delivery Intelligence Dashboard

# Project Overview
Developed an interactive Excel dashboard using 100 Amazon sales transaction records to analyze sales, revenue, regional performance, and delivery efficiency.

# Tools & Techniques
- Microsoft Excel
- Pivot Tables and Pivot Charts
- XLOOKUP and IFERROR
- Slicers and Conditional Formatting

# Key Features
- Analyzed sales by region and product category
- Evaluated delivery performance and order cancellations
- Created KPIs for total revenue, fast deliveries, top regions, and best-selling products
- Built an interactive dashboard for exploring sales insights

# Objective
To transform Amazon sales transaction data into meaningful business insights and support data-driven decisions.
